#### 发布签名证书

Android 云打包（HBuilderX → 发行 → 原生App-云打包 → 使用自有证书）使用以下签名证书，**请勿更换，否则已发布用户无法覆盖升级**：

| 项目 | 值 |
|---|---|
| 证书文件 | `D:\developer\ems\ems.keystore`（随仓库分发） |
| 格式 | JKS |
| 证书别名 | `ems` |
| 证书库密码 | `Iems@2026` |
| 证书私钥密码 | `Iems@2026` |
| 证书主体 | `CN=IEMS Energy, OU=Platform, O=NEIIC, L=Zhuhai, ST=Guangdong, C=CN` |
| 有效期 | 至 2126 年（100 年） |
| SHA1 指纹 | `B2:5E:F7:69:D0:3D:C0:5F:60:F2:E5:3D:15:9F:CA:96:61:2E:59:5E` |
| SHA256 指纹 | `31:0F:C5:E9:AF:5A:5F:20:33:A0:EA:F4:2F:6C:A7:6F:63:45:DB:BC:0A:40:60:64:BD:42:74:43:B4:CF:15:98` |

> 证书口令与指纹变更记录见 `.workbuddy/docs/APK安全误报处置方案.md` B2 节。
