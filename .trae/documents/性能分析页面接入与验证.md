## 已核对的一致性结论

1. 数据口径与网页版一致：`photovoltaicPower / storageDischarge / gridPowerSupply / loadPower / hour / date / month / voltage / loadFee / saveFee` 字段映射完全对齐。
2. KPI 公式一致：自给率 = pv/load、自平衡率 = (pv+discharge)/load、碳减排 = pv × 0.0005、费用优先取接口汇总，缺失时回退 电量 × 平均电价；月/年平均电价 0.6。
3. 接口入参与网页版一致；月周期 endDate 取「下月 1 号」（接口含头不含尾）。
4. uCharts 多轴配置已按 `uni_modules/qiun-data-charts/js_sdk/u-charts/u-charts.js` 源码要求编写：mix/line 多轴 series 均带 `index`，`opts.yAxis.data` 数量与 index 对应；ring 中心文案使用 `opts.title.name / opts.subtitle.name`。
5. 母线电压偏差率使用语义正确公式 `((v-750)/750)*100`，未沿用网页版的 `v/750*100`（网页版属缺陷）。
6. 站点上下文复用 `this.$store.state.currentSelectDevice`，缺 `areaLevelId` 时从 `state.userInfo.esIds` 补全，与项目现有页面写法一致。
